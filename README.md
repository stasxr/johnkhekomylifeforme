# Я могу всё — сайт-практика по книге Джона Кехо

Живой сайт: **https://doxoxo.com** (после настройки — см. ниже)

Статический сайт: аффирмации, ежедневная программа и техники подсознания.
Прогресс сохраняется у гостя в браузере, а у зарегистрированных пользователей — в облаке
(синхронно между устройствами).

## Из чего состоит

| Файл | Что это |
|------|---------|
| `index.html` | главная страница |
| `app.js` | вся логика: тема, аффирмации, прогресс, вход/регистрация |
| `config.js` | **единственный файл, который ты редактируешь** — сюда вставляешь ключи |
| `supabase/schema.sql` | SQL для создания базы прогресса |
| `privacy.html`, `terms.html` | заготовки юридических страниц |
| `CNAME` | привязка домена doxoxo.com к GitHub Pages |

## Шаг 1. Включить сайт (бесплатно, 2 минуты)

Сайт уже работает как статический — регистрация появится на Шаге 2.

1. Открой репозиторий на GitHub → **Settings** → **Pages**.
2. В разделе *Build and deployment* → *Source* выбери **Deploy from a branch**.
3. Branch: **main**, папка: **/ (root)** → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://stasxr.github.io/johnkhekomylifeforme/`.

### Привязать домен doxoxo.com
1. В **Settings → Pages → Custom domain** впиши `doxoxo.com` → Save.
   (Файл `CNAME` в репозитории уже содержит этот адрес.)
2. У регистратора домена (там, где куплен doxoxo.com) добавь DNS-записи:
   - Четыре записи типа **A** для корня `@`:
     `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - Одна запись **CNAME** для `www` → `stasxr.github.io`
3. Через несколько часов включи галочку **Enforce HTTPS** в настройках Pages.

## Шаг 2. Включить регистрацию и облачный прогресс (Supabase, бесплатно)

1. Зайди на **https://app.supabase.com** и зарегистрируйся (можно через GitHub).
2. Нажми **New project**. Придумай имя и пароль базы (запиши его). Регион — ближе к тебе (напр. Frankfurt).
3. Когда проект создастся, открой слева **SQL Editor → New query**,
   вставь целиком содержимое файла `supabase/schema.sql` и нажми **Run**.
   (Это создаст таблицу прогресса и защиту данных.)
4. Открой **Settings (шестерёнка) → API** и скопируй два значения:
   - **Project URL** — вида `https://xxxxx.supabase.co`
   - **anon public** ключ — длинная строка (её можно показывать, это норма).
5. Открой файл **`config.js`** и вставь их:
   ```js
   SUPABASE_URL:      "https://xxxxx.supabase.co",
   SUPABASE_ANON_KEY: "твой-anon-public-ключ",
   ```
6. Сохрани, закоммить и запушь (или загрузи `config.js` через сайт GitHub).
   Через минуту на сайте появятся кнопки **Войти / Регистрация** и синхронизация.

### Письма-подтверждения почты
По умолчанию Supabase просит подтвердить почту письмом.
- Оставь как есть для «боевого» режима (безопаснее).
- Для быстрого теста: **Authentication → Providers → Email** → выключи *Confirm email*.
- Позже подключи свой отправитель писем (SMTP) в **Authentication → Emails**, чтобы письма не попадали в спам.

## Шаг 3. Оплата / поддержка проекта (позже)

Сейчас кнопка «Поддержать проект» показывает благодарность-заглушку.
Когда захочешь принимать взносы:
1. Создай аккаунт **Stripe** (нужна верификация личности и банк для выплат — это делаешь ты сам).
2. Сделай **Payment Link** (разовый платёж или подписку) в панели Stripe.
3. Вставь ссылку в `config.js` → `STRIPE_PAYMENT_LINK`. Кнопка сразу заработает.
4. **Важно:** перед реальным приёмом денег заполни `privacy.html` и `terms.html`
   настоящим текстом (условия, возвраты) и укажи данные владельца. Проверь налоговые обязанности.

> Приём реальных платежей — это ответственность владельца сайта. Код-интеграцию можно
> подготовить, но аккаунт Stripe, верификацию и юридические документы оформляешь ты.

## Как проверить локально
Просто открой `index.html` двойным кликом в браузере — гостевой режим работает сразу.
Регистрация заработает только после Шага 2.
